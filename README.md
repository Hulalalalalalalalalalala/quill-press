# chainview

命令行 X.509 证书查看工具。当前版本支持版本查询和单张 DER 证书的字段查看。

## 构建与运行

```sh
cargo build --offline
./target/debug/chainview --version
```

输出：

```text
chainview 0.1.0
```

## 查看证书

```sh
./target/debug/chainview inspect certificate.der
```

成功时在标准输出逐行打印证书字段，顺序固定为主体、颁发者、序列号、有效期
开始、有效期结束，每行都带有字段名，例如：

```text
Subject: CN=测试证书,O=示例公司,C=CN
Issuer: CN=测试证书,O=示例公司,C=CN
Serial Number: 61375F20C30F448E87CF37490672204C7FF34FBC
Not Before: 2026-10-04T17:56:36Z
Not After: 2027-10-04T17:56:36Z
```

各字段含义：

- **Subject（主体）**：证书持有者的完整 X.500 名称。名称中的所有属性都会
  保留，包括重复出现的属性（例如多个 `OU`）；名称按 RFC 4514 形式展示，
  支持中文等非 ASCII 内容。没有主体名称的合法证书该字段显示为空。
- **Issuer（颁发者）**：签发该证书的 CA 的完整名称，展示规则与主体相同。
- **Serial Number（序列号）**：证书序列号，大写十六进制表示。
- **Not Before（有效期开始）** / **Not After（有效期结束）**：统一转换为
  UTC 时间，格式为 `YYYY-MM-DDTHH:MM:SSZ`，与运行机器所在时区无关。

### 输入限制

- 只接受 **DER 编码**的证书，不支持 PEM 文本，也不支持证书集合。
- 文件必须**恰好包含一张完整的 X.509 证书**。空文件、被截断或损坏的数据、
  只含公钥或其他 ASN.1 对象的文件都会被拒绝；完整证书之后附带任何字节
  （包括空白字符或另一张证书）同样会被拒绝。
- 本命令只解码并展示字段：**不验证签名、不判断证书是否受信任**，也不会
  因为证书尚未生效或已经过期而拒绝查看。

### 退出码与输出位置

- 查看成功：退出码 `0`，证书信息写入**标准输出**。
- 文件不存在或无法读取：退出码 `2`，原因写入**标准错误**，标准输出为空；
  该情况与证书格式不正确分别给出不同的错误说明。
- 证书格式不符合上述 DER 要求：退出码 `2`，原因写入**标准错误**，标准
  输出为空。
- 缺少文件路径、提供多个路径或使用未知参数：退出码 `2`，并在标准错误
  输出正确用法：

```text
Usage: chainview inspect <file>
       chainview --version
```
